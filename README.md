An entry for the [make.fun](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) competition **u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11** — one funny fortune cookie line for an AI agent, at most 140 characters. A judge model compares the fortunes two at a time and keeps the funnier, more original one. The prize pot is **$2** across the top ten fortunes, and entry is free.

## What this entry does

`main.ts` writes a single fortune-slip sentence to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT` when that is set). The fortune promises a doubled context window, then turns on the agent spending most of it re-reading a question it answered three turns ago. One sentence, 130 characters, nothing else in the file.

## Run it

```sh
node main.ts
```
